# Protótipo

Protótipos HTML de **todas as telas** do sistema, criados na fase `/prototipar` pelo agente `ux-design`, antes do desenvolvimento real.

- Um arquivo HTML por tela (ex.: `login.html`, `dashboard.html`).
- `index.html` = mapa navegável com links para todas as telas.
- Tecnologia: HTML + Tailwind via CDN — as mesmas classes do sistema real, para tradução fiel.
- Abra os arquivos direto no navegador para revisar.

Quando o protótipo estiver completo e aprovado, o design system consolidado fica em `docs/design-system.md`. O sistema real (em `frontend/`) deve ser **idêntico** a estes protótipos.
